# Rapira Tournament Bot + мини-приложение с ростером

Бот для группового чата: собирает состав на турнир, сам тегает игроков за 20/15/10/5 минут
до старта, ищет замену прямо в чате, рассылает запросы админам-новостникам и принимает
заявки в клан. Плюс отдельная HTML-страница с ростером/статистикой команды.

## Структура репозитория

```
main.py            — сам бот (pyTelegramBotAPI, без aiogram/pydantic — не ломается на Android)
requirements.txt    — единственная зависимость: pyTelegramBotAPI
Procfile            — команда запуска для Railway
.env.example        — пример переменных окружения
webapp/index.html   — мини-приложение с ростером и статистикой (отдельная статичная страница)
```

## Возможности бота

- `/new` — создать турнир (название → дата/время по МСК → состав `@username`)
- `/list` — список активных турниров и статус готовности
- `/edit` — изменить название / время / состав
- `/cancel_tournament` — отменить турнир
- `/find_players` — попросить админов найти прак/игроков: команда → что ищем (кнопки) →
  время → контакт, всё уходит админам в личку
- Приём заявок в клан: кнопка в мини-приложении открывает бота по ссылке
  `https://t.me/<бот>?start=apply`, бот по шагам спрашивает ник, ID, роль, скриншот
  статы и часовой пояс, затем пересылает заявку админам
- Автонапоминания за 20/15/10/5 минут до старта, с кнопками «✅ Готов» / «❌ Не смогу»
- Если игрок не подтвердился или нажал «Не смогу» — бот сам ищет замену среди всех,
  кто когда-либо писал в чат, кнопкой «🙋 Занять место»
- Права: `CAPTAIN_USERNAMES` — кто может управлять турнирами и рассылкой (пусто = все могут)

## Настройка бота в BotFather

1. Создай бота через [@BotFather](https://t.me/BotFather), сохрани токен.
2. Отключи Privacy Mode, иначе бот не увидит текстовые «готов» / «беру» в группе:
   `/mybots` → выбери бота → `Bot Settings` → `Group Privacy` → `Turn off`.
3. Добавь бота в группу команды.

## Настройки в коде (main.py, начало файла)

- `ADMIN_USERNAMES` — юзернеймы админов-новостников, которым бот пишет по `/find_players`
  и с заявками в клан. Каждый из них должен хотя бы раз написать боту (`/start`) или
  что-то в общий чат — иначе Telegram не даст боту написать первым.
- `CAPTAIN_USERNAMES` — юзернеймы капитанов, у кого есть доступ к управляющим командам.
  Пустой `set()` — доступ у всех.

## Локальный запуск (Pydroid или ПК)

Проще всего для теста — вписать токен прямо в файл:

```python
HARDCODED_BOT_TOKEN = "твой_токен_сюда"
```

Установи зависимость и запусти:

```bash
pip install pyTelegramBotAPI
python main.py
```

В Pydroid: Pip → Search/Install → `pyTelegramBotAPI`, затем открой `main.py` и нажми ▶️.

## Деплой на Railway

1. Залей содержимое этого репозитория на GitHub (не забудь оставить `HARDCODED_BOT_TOKEN = ""`
   пустым, чтобы токен не утёк в публичный репозиторий).
2. На [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub repo**.
3. Railway сам определит `Procfile` и `requirements.txt`.
4. Во вкладке **Variables** добавь `BOT_TOKEN` — токен от BotFather.
5. Для сохранности базы между деплоями добавь **Volume** (Settings → Volumes), примонтируй
   на `/data`, задай переменную `DB_PATH=/data/rapira_bot.db`.
6. Deploy — в логах должно появиться `Бот запущен, начинаю polling...`.

## Мини-приложение (webapp/index.html)

Статичная HTML-страница с ростером команды, счётом побед/поражений, списком турниров и
кнопкой «Подать заявку в клан». Сейчас данные (`roster`, `tournaments`) заданы прямо в
файле — правь их вручную в конце `<script>`.

Кнопка заявки ведёт на `https://t.me/Ammnyamm_bot?start=apply` — если юзернейм бота
изменится, поправь ссылку в файле.

Чтобы страница была доступна по ссылке, захости её отдельно, например бесплатно на
**GitHub Pages**:

1. В настройках репозитория → **Pages** → Source: `main` branch, папка `/webapp`.
2. Через пару минут страница будет доступна по адресу вида
   `https://<твой-логин>.github.io/<репозиторий>/`.

Позже это можно связать с ботом полноценно — сделать её настоящим Telegram Mini App
(кнопка меню бота открывает её прямо внутри Telegram) и подключить к базе `rapira_bot.db`,
чтобы ростер и статистика обновлялись автоматически по мере проведения турниров.

## Ограничения

- Тегать через `@username` можно только тех, у кого юзернейм установлен в Telegram.
- Совпадение игроков по username без учёта регистра; при смене ника в Telegram обнови
  состав через `/edit`.
- Время создания/редактирования турниров вводится по МСК, часовой пояс сервера отдельно
  не учитывается — важно, чтобы сервер/телефон, где крутится бот, был выставлен верно
  либо чтобы все понимали, что время именно московское.
- База данных (`rapira_bot.db`) — простой SQLite-файл на диске; при переезде бота на
  другой сервер её нужно скопировать вручную (или подключить постоянный Volume на Railway).
